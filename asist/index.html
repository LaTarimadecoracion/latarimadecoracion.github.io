Variables y Simbologías de AutoResponder

Puedes usar estas variables (Answer Replacements) en tus Mensajes de Respuesta para crear respuestas dinámicas y personalizadas. El celular las reemplazará automáticamente al momento de enviar el WhatsApp.

👤 Datos del Cliente

Variable Información que muestra Ejemplo de Salida
%sender% Nombre de contacto guardado (o su número si no existe) Juan Pérez
%name% Nombre completo del remitente Juan Pérez
%first_name% Primer nombre del remitente Juan
%last_name% Apellido del remitente Pérez
%number% Número de teléfono completo (con código de país) +5491167007723

💬 Mensajes y Grupos

Variable Información que muestra Ejemplo de Salida
%message% El mensaje completo que envió el cliente Hola, ¿tienen stock?
%message_url_encoded% El mensaje recibido formateado para usar en links web (URLs) Hola%2C%20%C2%BFtienen...
%group% Nombre del grupo de chat (vacío si es chat privado) Clientes La Tarima 🪵
%group_sender% Nombre del miembro que envió el mensaje en el grupo María Gómez

📅 Fecha y Hora

Variable Información que muestra Ejemplo de Salida
%time% Hora actual del teléfono (formato HH:MM) 18:45
%date% Fecha actual del teléfono (formato DD/MM/AAAA) 09/07/2026

🧩 Grupos de Captura RegEx (Avanzado)

Si configuras una regla con **Coincidencia de Patrón (Regex)**, puedes aislar textos del mensaje del cliente usando paréntesis ( ) y referenciarlos en la respuesta:

Variable Información que muestra Ejemplo de Disparador y Uso
%capturing_group_1% Muestra el primer fragmento capturado Disparador: menculas (\d+)cm
Mensaje: "mensulas 30cm"
Salida: 30
%capturing_group_2% Muestra el segundo fragmento capturado (si hay más paréntesis) Útil para capturar múltiples datos como nombre y edad.

🎲 Sintaxis para Variar Palabras (Respuestas Aleatorias)

Puedes hacer que el bot suene más humano alternando frases o emojis aleatoriamente usando esta estructura:

%rndm_custom_1_¡Hola!,¿Qué tal?,Hola amigo!%

El bot elegirá una de las tres frases al azar en cada respuesta.

🎯 Consejos y Sintaxis para Disparadores (Triggers)

Para captar correctamente las intenciones del cliente y soportar variaciones, configura el Tipo Coincidencia y escribe tu disparador así:

Tipo Coincidencia Sintaxis en Disparador Qué hace / Ejemplo de coincidencia
Coincidencia por similitud baranda Atrapa la palabra sola corrigiendo pequeños errores ortográficos del cliente (responderá a badanda, varanda, etc.).
Patrón (Wildcards) *baranda* Atrapa la palabra clave si está dentro de una frase más larga (responderá a "quiero una **baranda** para cama").
Patrón (Regex - Múltiples opciones) .*(precio|cuesta|sale|valor|costo).* Agrupa varias formas de preguntar lo mismo en una sola regla (responderá a "pasame el **precio**", "cuánto **cuesta**?", etc.).
