# La Tarima Decoración - Aplicación de Escritorio Windows 10/11

Esta carpeta contiene la solución **Híbrida de Escritorio** para Windows 10 y Windows 11 de **La Tarima Decoración**.

## 🚀 Cómo usar la aplicación

### Opción A: Abrir directamente (Modo Desarrollo / Prueba)
1. Haz doble clic sobre el archivo **`iniciar-app.bat`**.
2. La primera vez se instalarán automáticamente los componentes de Windows.
3. Se abrirá la ventana de escritorio nativa mostrando tu sitio web con sincronización instantánea.

### Opción B: Generar el instalador `.exe` para distribuirlo
1. Haz doble clic sobre el archivo **`construir-exe.bat`**.
2. Se generará un ejecutable nativo `.exe` listo para instalar en cualquier computadora con Windows 10 o Windows 11 dentro de la carpeta `dist`.

---

## ⚡ Características principales
- **Conexión e Integración Instantánea:** Los cambios realizados en la web se reflejan al momento en la app de escritorio.
- **Icono en la Bandeja del Sistema (System Tray):** Puedes minimizar la app junto al reloj de Windows.
- **Teclas Rápidas:**
  - `F5`: Recargar la aplicación.
  - `F12`: Abrir herramientas de desarrollo.
  - `Alt + F4`: Cerrar la aplicación.
  - `Ctrl + H`: Volver a la página principal.
